# Everest video components — craft guidance for Motion Bot

Source: https://www.everestchris.com/components ("Video components ·
Skills by Chris"). 69 components, three variants each, light and dark.
Wired 2026-11-01 as craft guidance only, following the v2.2 iart-ai
pattern: the router matches brief text to categories, and matched
categories add craft notes to the storyboard. Nothing here is a
renderer, and nothing here changes what a clip says.

## How to use a component

Recreate the PATTERN code-drawn in Remotion with the brief's own
words and numbers — typed text, ticking chips, growing bars, sliding
straps. Never render a fake screenshot of a real product, a real post,
a real person's handle, or a real model logo unless the brief itself
supplies that exact text. Never invent a number for a counter, a bar,
a receipt, or a score: counters only count numbers already in the
brief. Palette: parchment/gold by default; never purple, magenta, or
pink. Voiceover words and scene text still come only from the hook.

## Product UI (everest-product-ui)

Prompt types into a chat window and the reply streams in; input box
floating on the stage with attachment chips and a pulsing send;
model/effort dropdown that locks in; agent CLI with Read/Edit/Bash
tool calls ticking by, diff summary, done line; desktop agent app
with thread list and status chips running to done; lock-screen / Mac
notification then push-in; messaging app with typing dots and a done
card; agent cursor clicking through a website with step chips
stacking; files changed with green/red lines and a count-up;
chat left, built thing sliding out right; answer building line by
line with numbered source chips; permission prompt that pauses until
approved; call screen with live waveform and captions.

## Prompts and results (everest-prompts-results)

Prompt card, arrow, output under the wordmark; full prompt big and
readable with key phrases lighting up as read; output building in
stages under an elapsed timer, ending on a quiet time stamp; agent
screenshots its work, rings the bug, fixes it, ticks it; honest
failure call-out on the output — strike, ring, or red error line;
grid or reel of real things people built, each with its creator
handle and the model's mark (only when the brief supplies them);
local preview: URL types in, live site opens, link copies.

## Agents and workflows (everest-agents-workflows)

Coordinator agent's live task list: parallel sub-agents as rows,
each streaming status and ticking done, then a merged summary — a
real product surface, not a node diagram; a task passing between
real surfaces (personal agent → coding agent → back); Connectors
settings switching on one by one (Gmail, Slack, Notion, GitHub,
Calendar — only the ones the brief names); laptop lid closes, cloud
task card keeps progressing, done notification arrives; week strip
with recurring task pills firing on time; inbox sorting itself with
Reply/Skip/Urgent chips and a drafted reply sliding out; agent
cursor with a badge driving a real desktop app; SKILL.md card
dropping into the skills folder, new ability lighting up; memory
surface: facts saved from a chat, then recalled in a new chat.

## Models and benchmarks (everest-models-benchmarks)

3–5 model bars growing with logos at the base, winner taking the
accent (logos only when the brief supplies them); old score, arrow,
new score, delta counting up; lab model lineup as one clean spec
picker — tiers side by side with speed, price, intelligence, one
marked recommended; model versions on a dated line, each with its
key number; spec card: name, context, price in/out, date,
availability chips; container filling with documents up to the model
limit; sentence splitting into token chips while a counter climbs;
new model sliding into #1, the rest shifting down.

## Comparisons (everest-comparisons)

One prompt into two real app windows, timers running, finish order
landing; two results side by side under their wordmarks, winner
ticking, loser dimming; columns of price, context, speed, best-for
with ticks; long manual checklist collapsing into a single prompt
bar; clean recommendation table with the recommended model chip
landing in each row.

## Launch and news (everest-launch-news)

Lab mark, model name, version number ticking into place; official
post or system card scrolling with one sentence highlighted; real X
launch post recreated with its media playing (only when the brief
supplies the post); who gets it: tiers, regions, platforms lighting
up.

## Pricing and limits (everest-pricing-limits)

Subscription tiers with the one you need lifting; $ in / $ out per
1M tokens with the old price struck through; receipt printing for
one task: tokens, minutes, tool calls, total cost — all figures
only from the brief.

## Lower thirds and labels (everest-lower-thirds)

Speaker/guest name and role over A-roll: line, pill, or accent bar
sliding in and settling; small corner credit for third-party
footage with the real mark (only when the brief supplies it); one
to three floating keyword pills near the speaker's gesture; corner
badge counting through a list; quoted claim beside the speaker;
date / relative-time context for a clip or launch; credit for
whoever built the demo on screen (handle, repo, or channel — only
when the brief supplies it). Keep straps inside safe areas.

## B-roll frames (everest-broll-frames)

Third-party clip in a clean frame with a source line on the stage;
rounded presenter inset keeping the face on screen while a
full-frame graphic plays; product clip or screenshot centred over
a blurred, darkened copy of your own footage; two clips side by
side with a divider and labels (then vs now); vertical phone
capture of an app centred in a bezel; screen recording with a
smooth punch-in to one area and a ring on the target; past video
as a watch-page card.

## Evidence and quotes (everest-evidence-quotes)

Launch or reaction post in a styled card with the key phrase
highlighted and optional media (never presented as a real
screenshot unless the brief supplies it); system card, research
paper, or PDF page: rest dims, one line highlights, slow push-in;
product screenshot on the stage with a soft shadow and a source
chip; email (From / Subject / body) with the key line highlighted.

## AI usage and cost (everest-usage-cost)

Usage bar hitting the cap with the product's real limit banner
sliding in and a reset countdown; usage panel with 5-hour and
weekly bars filling to a percent. Caps and percents only from the
brief.
